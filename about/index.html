About this project

This project originated as a student research project at the ALR at KIT. The main focus was on Reinforcement Learning as is, yet the available codebase for performing reinforcement learning was insufficient. Basically, the only project was linesight, which is popular, but hard to work with if you want to try different algorithms etc. Basically, we needed for a gym-compatible environment, which led to the creation of this project.
